# v0.7 Release Validation

- 日付: 2026-10-05
- 対象: main `17d56d1` (`fix(rules/symbols): skip app-mode CHK006 for names the module reads (#564) (#575)`) とリリース準備の docs 変更
- Rust: `rustc 1.97.0 (2d8144b78 2026-07-07)` (ローカル。`release.yml` の `RUST_TOOLCHAIN` は `1.98.1`)

## 判定

v0.7 の release validation は合格した。spec §17 の exit criteria と、#495 で追加した
corpus regression gate を HEAD で測定し、全項目を満たした (deny / machete は
ローカル未実行。下表参照)。JSON / baseline の
`schema_version` は `"1"` のまま。JSON に `diagnostics` (#486) と `summary.files`
(#495) を追加したが、どちらも追加のみ。CLI flag、exit code、ignore syntax に
破壊的変更はない。追加した flag は `--no-auto-workspace` (#488)、設定は
`vendored` (#490)。

| Criterion | Measured | Result |
| --- | --- | --- |
| pre-commit gate | `make check` の fmt / clippy / test は通過。deny / machete はローカルに `cargo-deny` / `cargo-machete` がなく未実行 | PASS (deny / machete は CI で確認する) |
| CHK002 誤検知率 | 3.7% (1 fp / 27、未分類 0) | PASS |
| recall (`tp` label) | 48/48 | PASS |
| crash (exit 3) | 0 | PASS |
| CLI/config error (exit 2) | 0 | PASS |
| expectations (`reachable_runtime` 下限、ルール別件数の増加上限) | 6 project とも範囲内 | PASS |
| cold run (medium) | 全件 2 秒以内 (最大 58 ms、poetry) | PASS |

同じ corpus を v0.6.0 (`9341c0b`) で測ると、CHK002 誤検知率 6.1% (2 fp / 33、
未分類 5)、recall 39/48、exit 2 が 1 件 (langchain、非 UTF-8 fixture、#486)、
expectations は 14 項目が範囲外 (うち 6 項目は、v0.6.0 の JSON に
`summary.files` がなく `reachable_runtime` を測れないため) で、gate は不合格になる。

### expectations の更新

`scripts/oss-expectations.tsv` の行を今回の値に更新した。CHK008 / CHK009 /
CHK010 / CHK006 の減少 (#494、#507、#544、#545) が反映されていなかった。
llama_index の CHK003 は 185 → 201 に増えた。clone は commit で固定しているので、
増加は chokkin 側の変更による。上限を設定した `f1bdbbe` (#537) と HEAD を比べると、
増えた分はどれも以前 CHK010 (解決できない import) だった import で、#542 で
distribution に解決できるようになったもの。`torch` は package map に追加され、
`pptx` / `discord` / `llama_cpp` は接頭辞・接尾辞付きの名前 (`python-pptx` /
`discord-py` / `llama-cpp-python`) と照合できるようになった。その分 CHK010 は減っている。
精度の低下ではないので、上限を今回の値に合わせた。

## 実行コマンド

`oss-metrics.yml` と同じ手順をローカルで実行した。

```bash
make check
cargo build --release --locked --bin chokkin
git worktree add ../chokkin-v060 v0.6.0
cargo build --release --locked --bin chokkin \
  --manifest-path ../chokkin-v060/Cargo.toml --target-dir target/baseline
scripts/clone-oss-fixtures.sh
scripts/oss-metrics.sh -b target/baseline/release/chokkin -o target/oss-metrics-baseline -r 1
scripts/oss-metrics.sh -o target/oss-metrics --gate
```

実測詳細は `target/oss-metrics/report.md` を参照する。`target/` は生成物のため、
上表の release 結果を本ファイルに固定する。
