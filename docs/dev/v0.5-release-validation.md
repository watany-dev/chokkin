# v0.5 Release Validation

- 日付: 2026-09-28
- 対象: v0.5.0 (commit `79d7a21`、v0.4.1 はリリースせず変更を v0.5.0 に統合)
- Rust: `rustc 1.98.1 (48a229cea 2026-09-01)` (`release.yml` の `RUST_TOOLCHAIN` と同じ)

## 判定

v0.5 の release validation は合格した。spec §17 Phase 4 の exit criteria を、
PR #367 で測定した後の修正 (#375、#376、#407 など) を含む HEAD で再測定し、
全項目を満たした。JSON / baseline の `schema_version` は `"1"` のまま。CLI flag、
exit code、ignore syntax に破壊的変更はない。

| Criterion | Measured | Result |
| --- | --- | --- |
| pre-commit gate | `make check` (fmt / clippy / test / deny / machete) | PASS |
| CHK002 誤検知率 | 3.7% (1 fp / 27、未分類 0) | PASS |
| recall (`tp` label) | 48/48 | PASS |
| crash (exit 3) | 0 | PASS |
| cold run (medium) | 全件 2 秒以内 (最大 105 ms) | PASS |
| CHK003 件数 (`tp` と recall fixture を除く) | `573ff37` 288 → HEAD 170 | PASS |

## 実測

比較の baseline は `573ff37` (`chore: prepare v0.4.1 release (#284)`、Phase 4 着手前)。
corpus は `scripts/oss-clones.manifest` の 29 project と `scripts/oss-recall.manifest`
の recall fixture。

| Corpus | CHK002 `573ff37` | CHK002 HEAD | CHK003 `573ff37` | CHK003 HEAD |
| --- | ---: | ---: | ---: | ---: |
| 20-project set | 0 | 0 | 116 | 105 |
| R-01..R-07 corpus (9 projects) | 40 | 18 | 172 | 83 |
| Recall fixtures | 7 | 9 | 4 | 1 |

- CHK002 の唯一の fp は PR #367 時点と同じ `fastmcp`
  `script:examples/screenshot.py:pillow` (PEP 723 block で宣言、script 内で未使用)。
- CHK003 は PR #367 時点の 283 から 170 に減った。減少分の大半は mlflow
  (PR #367 時点 169 → 70)。
- 未分類 CHK003 は 132 件 (gate 対象外)。

## 実行コマンド

`oss-metrics.yml` と同じ手順をローカルで実行した。

```bash
make check
cargo build --release --locked --bin chokkin
git worktree add ../chokkin-baseline 573ff37
cargo build --release --locked --bin chokkin \
  --manifest-path ../chokkin-baseline/Cargo.toml --target-dir target/baseline
scripts/clone-oss-fixtures.sh
scripts/oss-metrics.sh -b target/baseline/release/chokkin -o target/oss-metrics-baseline
scripts/oss-metrics.sh -o target/oss-metrics --gate
```

実測詳細は `target/oss-metrics/report.md` を参照する。`target/` は生成物のため、
上表の release 結果を本ファイルに固定する。
