### Blind spots (precision unverified)

Rules with **Reported > 0** but **Coverage = 0%** have findings on the corpus
but no tp/fp labels yet. These need #85 WS2 (remove-and-test) or manual
triage before claiming real-world precision:

- **CHK001** — 1265 unused-file findings (expected on library/test trees)
- **CHK005** — 7 misplaced-dependency findings
- **CHK006** — 13219 unused-export findings
- **CHK007** — 253 unused-reexport findings
- **CHK008** — 100 unlisted-binary findings
- **CHK009** — 19 duplicate-dependency findings
- **CHK010** — 870 unresolved-import findings

Rules with **Reported = 0** (CHK004 on this corpus) have neither precision nor
recall signal — the validation set did not trigger them.

Only **CHK002** has complete quantitative backing on this run. CHK003 has one
sentinel and 53 policy-proven optional-import false positives; the remaining
910 findings are bucketed but deferred pending validation.

### Classification method

963 OSS CHK003 rows were bucketed with `scripts/generate-chk003-labels.py`.
Optional try-import findings are policy-proven false positives. Test/docs/typing
and no-lockfile findings are heuristic buckets only, so they remain `deferred`
instead of being presented as ground truth. Manual validation and FP reduction
belong to v0.4 A1–A3.

Regenerate after a fresh metrics run:

```bash
make oss-metrics
python3 scripts/generate-chk003-labels.py target/oss-metrics/findings.tsv
```
