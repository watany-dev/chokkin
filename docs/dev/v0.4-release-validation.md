## 実施内容

- default CHK003 を runtime import 中心にし、type / test / docs / dev context は
  `--strict` で報告する policy を fixture で固定した。
- optional try-import と platform-guarded import を hard error にせず、conditional
  CHK003 candidate として残した。
- `typing` と `TYPE_CHECKING` の alias を静的に追跡し、parse cache unit version を
  `parse-v2` に更新した。
- local wheel の `METADATA` / `top_level.txt` / `RECORD` だけを読む offline harvester
  を追加した。network access、seed の自動上書き、project code の実行は行わない。
- ADR 0003 で safe autofix、ADR 0004 で semver / compatibility surface を確定した。
