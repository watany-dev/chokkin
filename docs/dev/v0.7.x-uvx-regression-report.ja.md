# chokkin v0.7.x デグレード・改善状況レポート(uvx 実測)

計測日: 2026-10-17 / 計測者: Claude Code(本セッション)
対象: PyPI 公開済みの `chokkin==0.7.0, 0.7.2, 0.7.3, 0.7.4, 0.7.5, 0.7.6, 0.7.7`(比較基準として `0.6.0` も計測)。
**0.7.1 は PyPI に公開されていないため `uvx chokkin==0.7.1` は起動できず、対象外。**

## 1. 結論

- **0.7 系は版を追うごとに一貫して改善しており、0.7.7 が全版で最良。** warning 以上の finding は 45 プロジェクト合計で 10,215(0.7.0)→ 2,538(0.7.7)。`docs/dev/release-validation.ja.md` の exit criteria は 0.7.5 以降で精度床・expectations が PASS、0.7.7 で recall も 868/868 となり**初めて全項目 PASS**。
- **デグレードは各版に存在したが、すべて次版以降で解消済み。** 最大のものは 0.7.4/0.7.5 の transformers 約 5.6 倍遅化(1.3 s → 7.5 s、全体 +68%)で、0.7.6 で回復、0.7.7 でさらに 0.7.0 比 30% 高速化。
- **0.7.7 で新たに増えた finding は notebook 読み取り(#962)の副作用が中心**: llama_index の `docs/examples/*.ipynb` 由来で default +281(うち info 253)、strict +573 error/certain。設計上は正しい挙動(notebook は entry)だが、strict 利用者には実質的なノイズ増。
- **0.7.7 時点で未解決の既知バグ**: #994(notebook 変換が括弧内 `%` 行を壊し、cell 欠落 → CHK002 FP が `likely` で出る。本レポートで再現)、#996(`--probe`/`--trace` の制御文字未 escape)、ほか v0.7.7 roadmap #970 の Should 以下 24 件。

## 2. 計測方法

| 項目 | 内容 |
|---|---|
| 起動 | `uvx chokkin==<ver> --version` で各版を取得し、uv cache 内バイナリを直接実行(`--version` は全版正しい値を返す) |
| コーパス | `scripts/oss-metrics.py` の 45 プロジェクト(OSS 35 + fixture 10)。`target/oss-clones/` に clone |
| 手順 | `scripts/oss-metrics.py -b <bin> -o <out> -r 1 --with-strict --baseline <前版出力>`。毎回 `.chokkin` 削除 + `--no-cache` の cold 計測。全 8 版 exit 0 |
| 版間差分 | `finding-diff.tsv` / `finding-diff-strict.tsv`(NEW / GONE / CHANGED、キーは slug + fingerprint) |
| 実行時間 | 上記 `-r 1` とは別に、主要 8 プロジェクト × 6 版 × 3 round を交互実行し中央値を採用(`--reporter json --no-exit-code --no-cache`) |
| 追加検証 | 自作 fixture で CHANGELOG 記載のバグ修正を各版で再現(§7) |
| 制約 | 解析対象コードは一切実行していない(静的解析のみ)。ラベルは `scripts/oss-labels.tsv` の既存分類を使用 |

JSON の `schema_version` は 0.7.x 全版で `"1"`、出力互換性の破壊はない。
