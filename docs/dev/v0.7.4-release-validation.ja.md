## 判定

v0.7.3 → v0.7.4 にリリースを止めるデグレードはない。exit criteria はすべて PASS、gate 6
(CHK003 growth) と gate 7 (`tp` の消失) も PASS。既定 filter の warning 以上は
3,754 → 2,970 件 (-784) で、減少の大半は FP 修正による消失 (other) か、warning → info
への降格 (CHANGED) で説明がつく。

ただし次の 5 点は記録しておく。1〜3 は #755 で記録したもので、HEAD でも変わらない。

1. **oss-metrics の Downgraded 58 件は confidence の降格ではない。** 全件が HEAD の
   `--strict` でも同じ severity / confidence (error/certain か error/likely) のまま残っており、
   中身は `examples/` を dev context にした #709 (#694) による文脈の再分類だった。
   本当の降格 (severity / confidence が下がったもの) は `finding-diff.tsv` の CHANGED 側に
   349 件ある (下記)。
2. **#688 (#679) の map 追加で openai-python に strict のみの FP が 2 件出る。**
   `griffe` を `griffelib` だけに Certain で解決するため、`griffe` (1.x) を dev group に
   宣言している openai-python で CHK002 `griffe` と CHK003 `scripts/detect-breaking-changes.py:griffe`
   が同時に出る (bisect で `d19a8c3~1` には無く `d19a8c3` から出ることを確認)。
3. **#752 (#735) で openai-python の `build` group の `hatchling` が strict の CHK002 になる。**
   build script (`scripts/hatch_metadata.py`) の import を deps rule 全体の resolution から
   外したため、`hatchling` を宣言している `build` group 側の使用も見えなくなった
   (`157c6ce~1` には無く `157c6ce` から出る)。
4. **#756 (#721) の降格は requests に効いていない。** requests の pinned checkout は
   `pyproject.toml` に `requires-python` を持たず、`setup.py` の `python_requires=">=3.8"` だけで
   宣言している。chokkin は `setup.py` / `setup.cfg` の `python_requires` を読まない
   (`requires_python` を埋めるのは `src/manifest/pyproject.rs` だけ) ので、requests の
   `src/requests/cookies.py:dummy_threading`、`tests/conftest.py:BaseHTTPServer` /
   `SimpleHTTPServer` (いずれも `fp` label) は HEAD でも CHK010 warning/likely のまま。
   CHANGELOG の該当項目はこの制限を書く形に直した。
5. **#754 (#719) で実行時間が 7〜15% 遅くなった。** budget (medium ≤ 2 s) には余裕があるが、
   全 project で再現する (下記「実行時間」)。

2 と 3 はいずれも dev group / dev context なので既定 run には出ず、gate にも掛からない。
