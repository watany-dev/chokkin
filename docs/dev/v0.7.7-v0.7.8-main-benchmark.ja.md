## 2. 判定

main は v0.7.7 / v0.7.8 のどちらに対しても、リリースを止めるデグレードはない。いつもの corpus の
exit criteria は v0.7.8 と main がすべて PASS、`tp` の消失は両遷移とも 0、crash / CLI error 0。
新規 30 corpus でも exit 2 / 3 は 0。

1. **main は v0.7.8 の遅化を直した。** v0.7.8 は airflow 1.44 s → 4.38 s (3.0 倍)、llama_index
   1.17 s → 2.31 s (2.0 倍) と大きく遅くなっていた (module 名の文字列を workspace member ごとに
   全ファイルで引いていた。CHANGELOG Unreleased、#1087)。main は airflow 1.68 s、llama_index
   1.11 s で、v0.7.7 比 +16% / -5%。他の project は v0.7.7 比 +3〜+20% で、examples / docs /
   Django の規約を読むようになった分の仕事が増えている (§8)。
2. **いつもの corpus の warning 以上は 4,416 → 4,328 → 3,738 件 (v0.7.7 比 -15%)、info は
   3,133 → 3,352 → 3,305 件。** v0.7.8 の減少は app-mode の CHK001 を warning / info に落とした
   #1026 (CHANGED 492 件) で、main の減少は Django の installed-app 規約を entry にした #399
   (#1077) で、wger / weblate / saleor / healthchecks / django の CHK001 233 件、CHK006 301 件、
   CHK010 116 件、CHK002 33 件が消えた。label 付きの `fp` の消失は CHK006 1 件、`tp` は 0。
3. **新規 30 corpus の warning 以上は 4,446 → 4,283 → 4,282 件、info は 3,605 → 3,643 →
   3,435 件。** v0.7.8 で ansible (943 → 809) と litellm (2,073 → 2,045) が #1026 で減り、main で
   wagtail (info 297 → 154) と pretix (info 376 → 296) が #399 で減った。netbox だけは main で
   info が 1,086 → 1,103 と増えた (`@register_search` を use と見ない。§10)。
4. **precision は動いていない。** label 付きの CHK003 / CHK004 / CHK005 は 100%、CHK006 93.1%、
   CHK010 94.7% (v0.7.7 は 93.9%)、CHK002 74.1% (v0.7.7 71.6%)。CHK001 は 28.3% (floor 25%)。
   main の CHK002 は unclassified 0 になった (v0.7.7 は 36 件、v0.7.8 は 33 件)。
5. **v0.7.7 の recall / expectations の FAIL は label の artifact。** label は main の checkout
   向けに書かれており、v0.7.7 は transformers の `examples/` を読まない (#1023 以前) ので
   そこの `tp` 75 件を出せない。dagster-open-platform / prefect-collection-registry の
   expectations も plugin (#401) 以前の値。v0.7.8 以降はすべて PASS。
6. **新しい FP class が 3 つ見つかった (§10)。** ansible の module docstring 定数 (CHK006、v0.7.8
   から 127 件)、netbox の `@register_search` (CHK006、main から 58 件)、pretix の
   package-map 欠落 (CHK010、main から 9 件)。

## 10. フォローアップ候補

1. **#399 (#1077、Django installed-app 規約) が CHANGELOG の Unreleased に無い。** main の
   変化の大半を説明する変更なので、リリース前に追記する。
2. **ansible の module docstring 定数 CHK006 (v0.7.8 から 127 件)。** `lib/ansible/modules/*.py` の
   `DOCUMENTATION` / `EXAMPLES` / `RETURN` が warning/likely で出る (v0.7.7 では 45 件、ファイルが
   到達していなかった)。ansible が実行時に読む規約で、FP。module-level の大文字文字列定数を
   docstring 扱いにするか、ansible 規約を plugin で持つ。
3. **netbox の `@register_search` CHK006 (main から 58 件)。** `*/search.py` の `*Index` class は
   `netbox.search.register_search` で登録される。#399 で到達したファイルの decorator を use と
   見ていない。`@register` / `@admin.register` と同じ扱いに広げるか、decorator 付き class を
   likely に落とす。
4. **pretix の package-map 欠落 (CHK010 9 件)。** `django-i18nfield` → `i18nfield`、
   `django-localflavor` → `localflavor`、`paypal-checkout-serversdk` → `paypalcheckoutsdk` /
   `paypalhttp` が `data/package-map.seed.json` に無い。seed に足して `make check-generated`。
5. **app-mode corpus の CHK002 誤検知率 48.1% (25 fp / 52、記録のみ)。** fp は wger 8、
   weblate 5 など settings 経由で使われる package。#399 で分母が減って比率が上がった。残る fp の
   原因 (plugin 規約、`AUTHENTICATION_BACKENDS` などの文字列参照) を分類する。saleor の
   `google-cloud-storage` NEW 1 件 (error/likely) もここで確認する。
6. **uvicorn `tests/importer/raise_import_error.py:does_not_exist` の CHK010 (warning/likely、
   main)。** 意図的に ImportError を起こすテスト。tests 配下の単発なので優先度は低い。
7. **`scripts/clone-oss-fixtures.sh` は manifest の `ref` 列が空だと落ちる。** 新規 30 corpus の
   clone で踏んだ (default branch を取ってから SHA を lock に書く経路が無い)。
8. **`--explain` が info の finding に一致しない (v0.7.8)。** 原因未確認。
9. **v0.7.7 の label artifact。** recall label と expectations は main 向けなので、2 つ前の版に
   そのまま当てると FAIL する。古い版を測るときは `report.md` の recall / expectations 行を読み飛ばす
   か、label に導入版を持たせる。
